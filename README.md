## Overview

BioQuest is an educational platform that gamifies learning Mediterranean marine species identification. Built on the YOLOFauna AI engine, it combines a structured species academy, interactive quizzes, satellite-based exploration maps (EUMETSAT), and achievement systems.

## Features

- 🏫 **Academy**: 1,369 species with AI-generated flashcards and diagnostic descriptions
- 🎮 **Quizzes**: Adaptive difficulty using AI-generated distractors (visually similar species)
- 🛰️ **Atlas**: Real EUMETSAT satellite imagery (True Colour RGB) for environmental context
- 🏆 **Achievements**: Tier mastery, streak tracking, species milestones
- 🔗 **FotoFauna pipeline**: Graduate from learning to contributing real identifications
